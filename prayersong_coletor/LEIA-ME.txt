COLETOR DE PAGINAS PUBLICAS DO PRAYERSONG

Requisitos: Node.js 20+ e internet.

No Windows:
1. Extraia este ZIP.
2. Abra o terminal dentro da pasta prayersong_coletor.
3. Execute: npm install
4. Execute: npx playwright install chromium
5. Execute: npm start

O navegador abre e captura a pagina inicial e /create, gerando HTML renderizado,
texto, capturas de tela e ate 200 arquivos publicos (CSS, JS, imagens e fontes)
na pasta captura. Se houver aviso de cookies, a captura pode inclui-lo.

LIMITES:
- Nao baixa codigo do servidor, banco de dados, nem checkout privado.
- O formulario pode depender de APIs, cookies e scripts do servidor.
- Os arquivos HTML salvos nao necessariamente funcionam offline.
- O coletor nao interage com pagamento nem tenta acessar areas privadas.
- Use o material para analise e traducao, respeitando direitos autorais.
- Substitua marca, fotos de clientes, videos e depoimentos por conteudo proprio.

Depois de executar, compacte a pasta captura e envie aqui para traducao/adaptacao.
