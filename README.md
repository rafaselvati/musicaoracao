# PrayerSong - Página em português brasileiro

Página HTML estática para GitHub e Vercel.

1. Abra `index.html` e altere `const CHECKOUT_URL = ""` para o endereço real do seu checkout.
2. Publique o repositório na Vercel como projeto estático (sem comando de build).
3. Teste botões, áudio, imagens e checkout no endereço publicado.

**Atenção:** o arquivo de origem era uma captura HTML de uma página dinâmica. Scripts originais foram removidos para evitar redirecionamentos ou operações inesperadas. Integrações de pagamento, questionário e personalização precisam ser conectadas aos seus serviços. Valores em USD e nome de exemplo foram mantidos como no original.
